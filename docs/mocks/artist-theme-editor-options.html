Artist pages · theme editor

More ways to make it yours

The inline Theme panel gets four tabs (Layout, Colour, Type, Shape) so it can hold a lot more without becoming one endless scroll: sixteen display faces and a body text choice, a real corner radius, button shapes and spacing, gradient backgrounds, text colour and palettes picked from your own photos, and Reel, a new layout where the page scrolls sideways. Everything still repaints the page as you click. Drawn on @probablysunday.

5

Reel: the page scrolls sideways New

A fourth layout. The header is the first panel, then your blocks run off to the right in columns as tall as the screen. Scrolling with a mouse wheel or trackpad moves it sideways, as do the arrow keys and the buttons in the bar along the bottom, which also shows how far along you are. On a phone each part is a full-screen card you swipe through.

Bio

Sunday is a New Zealand based producer, crafting bass-heavy dance music that thrives on the weird, the wonderful, and the unexpected. Blending weighty low-end with left-field textures, warped grooves and high-energy club rhythms, Sunday pushes UK-inspired sounds into fresh territory while keeping one foot firmly on the dancefloor.

Already earning support from the likes of Notion, Hermitude, Burt Cope, MSFT, Jeremy Sylvester and many more. Sunday’s music is finding its way into sets from some of the scene’s most respected selectors. With an ever-evolving sound and a focus on creating tracks that surprise as much as they hit, Sunday is quickly becoming a name to watch.

Build notes

  • Theme tokens. Add body, case, nameSize, radius (0 to 32, replacing hard and soft), buttons, density, background (solid, gradient or photo, with a second colour), texture, ink (auto or a colour) and tint. parseTheme reads old themes field by field: hard becomes 0, soft 16, everything else gets today's value, so no page changes until it's edited. Themes are JSON, so no migration.
  • Fonts. The new faces are declared with next/font like today's, without preloading. A browser only downloads a face a page actually uses, so visitors still load one or two fonts.
  • Palettes from photos. Worked out in the browser from the page's banner, portrait, release covers and posters (a small colour quantiser on a scaled-down copy). Nothing new is stored except the colours picked.
  • Text colour runs through the same contrast check as the accent: below 4.5 : 1 on the background it's flagged and Auto is used instead.
  • Reel is a layout like Headliner, Wall and Stage: the header panel, then a CSS grid flowing in columns (rows the height of the screen) that uses each block's measured height. Vertical wheel movement is turned into sideways scrolling; arrow keys and the bar step by a column. Phones use swipe cards with scroll snapping. In edit mode the page shows the normal grid to arrange, with a Preview sideways button in the dock.
  • Undo for theme changes uses the editor's existing undo, so a Shuffle or a palette can be taken back.
  • The theme editor pages (dashboard and admin) get the same four tabs, so a theme looks the same wherever it's edited.
