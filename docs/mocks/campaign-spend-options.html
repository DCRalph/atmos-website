Campaign spend and conversion

Three ways to record what you spent on a campaign and see what it sold. All three save spend as an event cost, so profit and break even stay right without entering anything twice. The conversion card at the bottom is the same in every option.

A Tag a cost B Spend on the sources card C Campaigns tab Conversion card shared

ATag a cost with where it went

The Costs tab already has "Other costs". Each row gets an optional tag: a source or campaign picked from the tags this event's orders already carry, or typed fresh. The overview's sources card becomes a table that sets spend against what each tag sold.

BEnter spend right on the sources card

The same table as A, but the Spend column is editable in place. Click "Add spend" on a row, type an amount, and it saves straight away as a cost labelled with that source. It still appears in Costs, where it can be renamed or removed.

Why pick it: the fastest loop. You look at a source, see it has no spend, add it, and the return appears.
  • Catch: you can only add spend once a source has at least one checkout. Spend on a campaign that sold nothing has to go in through Costs (option A's tag field is still there).
  • Organisers who can't edit costs see the table read only.

CA Campaigns tab that also makes the links

A new tab on the event. You create a campaign up front: name, where it runs, what it cost. It hands back the tracked link (and short link and QR, using what short links already do) so the tags can't be mistyped. Results sit beside each one.

Comes with every option, no UI:
  • utm_content recorded and shown, for telling two versions of the same post apart.
  • Tags kept for the visit, so someone who lands on a tagged link and browses before buying still counts.
  • When a link has no tags, the referring site fills in the source (instagram.com becomes "instagram") instead of "direct".
